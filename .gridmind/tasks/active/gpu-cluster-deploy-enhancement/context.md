# 任务上下文

## 任务概述

**任务ID**: task-20260224-143052
**名称**: GPU集群部署配置增强 - 最终实施计划
**类型**: cluster-deploy
**模式**: 半自动 (1)

## 目标

增强 `gpu-cluster-deploy` 项目的配置能力、设备一致性检查和模块化部署功能。

## 核心需求

### 1. 批量节点配置
支持 `/etc/hosts` 格式的批量节点配置，同时允许个别节点覆盖默认配置。

**决策**:
- 使用 `NodeBatchConfig` 数据类封装批量配置
- 创建 `HostsParser` 解析 hosts 格式文本
- 配置合并采用"批量默认 + 个别覆盖"策略

### 2. 磁盘格式化选项
添加 `format_disk` 选项控制是否在部署时格式化磁盘。

**决策**:
- 在 `StorageConfig` 中添加 `format_disk: bool = False` 字段
- 默认不格式化，防止数据丢失
- 格式化前需要用户确认

### 3. local_file 澄清
明确 `local_file` 是执行部署的本地机器上的文件路径，不是远程节点路径。

**决策**:
- 更新文档说明
- 配置验证时检查本地文件是否存在

### 4. 设备序列一致性检查
确保所有节点的 RDMA (mlx5_*) 和以太网 (ens*) 设备序列一致。

**决策**:
- 创建 `device_checker.py` 模块
- 支持 RDMA 和以太网两类设备的检查
- 检测缺失、多余、不连续的设备
- 生成修复建议报告

### 5. 跳转服务器认证增强
支持跳转服务器到集群节点的独立认证配置。

**决策**:
- 在 `JumphostConfig` 中添加 `node_auth` 字段
- 支持与跳转服务器不同的认证方式
- 向后兼容现有配置

### 6. 模块化执行
每个部署功能可以单独执行。

**决策**:
- 创建 `DeploymentModule` 基类
- 实现模块注册系统
- 支持分类执行（network/storage/gpu等）
- 支持执行计划导入/导出
